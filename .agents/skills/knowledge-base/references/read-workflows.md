# 读取工作流

仅在查询知识或生成写作选题时读取。

## 查询库内观点

1. 运行 `python3 scripts/kb.py search "关键词"`，并查看 `INDEX.md`。
2. 优先读取相关 Wiki 的当前结论、证据、矛盾和待确认问题。
3. 下钻到 Wiki 引用的原子笔记；只有需要核对事实时才读取 `raw/` 原文。
4. 回答顺序：直接结论 → 资料事实 → 用户已有判断 → 必要的 AI 推断 → 来源。
5. AI 推断必须显式标记。库内证据不足时，直接说「知识库内暂无足够依据」，不使用模型常识悄悄补齐。

## 生成写作选题

1. 读取 `INDEX.md` 中最近的笔记和相关 Wiki，必要时用 `search` 聚焦用户指定主题。
2. 候选选题必须满足：目标读者明确、存在冲突或新意、至少两条来源、现在写有理由、下一步可执行。
3. 每个结果包含：标题、核心角度、目标读者、为什么现在写、关键证据、来源路径和下一步动作。
4. 用户只要求建议时在对话中输出，不写文件；用户要求保存、采用或进入创作时，再读取写入工作流并落到 `briefs/`。
5. 不为了凑数量输出证据不足的宽泛标题。
